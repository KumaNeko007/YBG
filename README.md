## 実施
- 5巻展開・CRC・結合 SHA256、preview9差分/ GitHub ZIP SHA256、旧HTMLの分割再結合 SHA256一致。差分適用。118原画の基準SHA一致。183登録素材ファイルのpreview9台帳SHA一致。
- ゲーム名と主人公名、バージョン、衣装4件と素体1件を変更。名称は内部IDで追跡。ゲーム内の女神変身用語を維持。原画・全登録画像は非変更。旧ポスターの文字は画像焼込みのため旧版歴史資料として明示したまま（改版未実施）。
- リセットに baseNUnlocked=false, baseArt=B, pendingBaseArt削除、タイトルタップ回数リセット、初期所有再同期を追加。同一ドメインの無関係データは消去しない。既存セーブキーおよび2ID移行を維持。
- 初期衣装 basic と ynew5_cross は旧確定仕様・テストで初期配布2着。通常の未獲得は非表示、確認用チェックボックス（全ステージ・全衣装・旅日記）を意図的に維持。第1隠し10タップ、第2隠し20タップ（同一16秒窓）維持。第2対象は独立47＋素体選択枠1（8絵）。古い「29着」表示を動的件数に修正。
- タイトル一行化、衣装画面を縦向きで拡大、設定ボタン短縮・nowrap。衣装DPR直描画を維持。マニュアルで衣装立ち絵をタップ→全画面、ピンチ・パン・ダブルタップ・閉じる・一覧位置復帰。宝箱4種類、敵15体種別/強さ画像・4ボス＋各部隊の画像を拡大し全画面対応。衣装一覧はネイティブスクロールに変更。宝箱・敵の拡大は元アトラス領域の原寸切出しを使用（高解像度素材の新規生成なし）。
